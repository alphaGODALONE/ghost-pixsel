# GHOST PIXSEL
A complete static front-end starter for the Ghost Pixsel Minecraft network.

## Run
Open `index.html` in a browser, or serve this folder with any static web server.

## Included
- Home / live-looking server status UI
- Server Status
- Ghost Profile
- Leaderboards
- Shop
- Wallet & Payment
- Hall of Fame
- Staff
- Rules
- Tickets
- News & Events
- Vote
- Community
- Admin Panel
- Responsive dark/cyber gaming UI
- Copy server address
- Local demo interactions/toasts

## Next backend integrations
Replace mock values in `assets/app.js` with API calls for:
- Minecraft server status
- Player profiles and stats
- Leaderboards
- Authentication
- Payments
- Tickets
- Admin authorization
- News/events persistence
